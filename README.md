# 診察室の「お医者さんからの生活指導」をその場で印刷・お渡しするAIアシスタント

## 💡 解決したい課題
高齢の患者さんにとって、診察室で医師から告げられる生活指導や食事・運動の注意点をその場ですべて記憶したり、急いでメモしたりするのは大きな負担です。
しかし、医師側もカルテ記載や次の患者の対応で忙しく、一人ひとりに合わせて分かりやすい「手作りの生活指導パンフレット」をその場で用意する時間はありません。

## 🚀 プロダクトの概要
お医者さんが診察室で患者さんと話した内容（音声の文字起こし、または簡単なメモ）をもとに、AIが**「高齢者にもわかりやすい、大きな文字と噛み砕いた言葉」**の生活指導書を瞬時に作成するシステムです。
医師が画面でサッと確認して「OK」を出けば、その場でワンタップで印刷して患者さんに手渡すことができます。

## 🛠️ 使用技術
* **LLM / AI**: Claude (Anthropic API) —— 医師の言葉を患者向けの分かりやすい表現・レイアウトに要約・変換
* **アーキテクチャ・設計**: **完全ステートレス設計（データ非保存）** —— 個人情報や機微なカルテデータをサーバーに一切蓄積せず、その場の生成・出力に特化

## ✨ こだわり・目指すゴール
* **現実的なプリンター連携**: 重厚な院内システムや電子カルテの刷新は不要。スマホから既存の病院内プリンターへの出力機能のみに絞ることで、セキュリティと導入のハードルを最小限に抑えます。
* **プリンター障害に備える「一時バッファ（最長1時間で自動消滅）」**: インク切れや紙詰まりなどの現場トラブルに対応するため、データは即時消去せず最長1時間だけ一時保持。時間が来れば自動で完全消滅し、医師がスマホにデータを持ち越す心配をなくします。
* **「一患者・一セッション完結型」による誤認防止**: 複数の患者データを同時に保持せず、「吹き込み ➔ 印刷 ➔ 消去」のサイクルを徹底。他の患者への渡し間違い（誤認交付）を構造的に防ぎます。
* **人間の最終確認（Human-in-the-loop）**: AIが自動出力するだけでなく、必ずお医者さんの目で確認してから印刷・お渡しする安全な設計にします。
